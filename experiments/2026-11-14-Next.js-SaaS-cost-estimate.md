## Idea

The boilerplate's selling point is AI cost observability, but it only shows cost *after* tokens
are spent; a founder choosing models and plan prices has no way to see beforehand whether a
plan loses money on a given model. Add `pnpm cost:estimate`, an offline CLI that takes a usage
profile (requests per month, average input and output tokens) and prints, for every model in
`AVAILABLE_MODELS`, the monthly LLM cost, the smallest plan in `PLANS` whose token quota covers
it, and (with `--plan`) the margin left from that plan's price.

Other ideas considered: an `env:check` doctor for `.env.example`; a generated plan-comparison
table in the README from `PLANS`.

## Success checks

1. `pnpm -s cost:estimate --requests 1000 --input 1500 --output 500` exits 0 and prints a table
   with one row per entry of `AVAILABLE_MODELS` (6 rows), where GPT-4o costs `$8.75`,
   Claude 3.5 Sonnet `$12.00` and Gemini 2.0 Flash `$0.00`, and states that the 2,000,000
   tokens/month fit the `pro` plan (the smallest plan whose `tokenQuota` covers them).
2. Adding `--plan pro` to the check-1 command adds a margin column based on the Pro price
   ($49.00/month): the Claude 3.5 Sonnet row shows a margin of `$37.00`. Adding `--plan starter`
   instead prints a warning that 2,000,000 tokens exceed the Starter quota of 500,000.
3. Adding `--json` to the check-1 command prints valid JSON (parsable by `node -e
   'JSON.parse(require("fs").readFileSync(0,"utf8"))'`) holding 6 model entries, each with a
   `modelName` and a numeric `costUsd`.
4. Bad input (`--requests -5`, `--requests abc`, a missing `--output`, an unknown `--plan`)
   exits non-zero with a usage message on stderr.
5. Prices and quotas are read from `AVAILABLE_MODELS` (`src/config/models.ts`) and `PLANS`
   (`src/lib/billing/plans.ts`): the new non-test source files contain no per-token price or
   quota literals (no `0.0025`, `0.015`, `500_000`, `5_000_000`, `4900` etc.).
6. A new vitest file for the estimator logic passes with at least 6 tests, and `pnpm typecheck`,
   `pnpm lint` and `pnpm test` all pass.
